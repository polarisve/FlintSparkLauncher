# Flint Spark Launcher (FSL)

Flint Spark Launcher（简称 FSL）是一款 Minecraft: Java Edition 启动器。

## 基于 HMCL 开发

FSL 是 [Hello Minecraft! Launcher (HMCL)](https://github.com/HMCL-dev/HMCL) 的第三方修改版。
游戏启动、下载、账户登录等底层功能来自 HMCL，版权所有 © 2013-2026 huangyuhui 及贡献者。

FSL 与 HMCL 一样以 [GPL v3](LICENSE) 开源，并遵守 HMCL 依据 GPLv3 第七条附加的条款：

1. 修改版须改名或修改版本号以示区别（本项目已更名为 FSL）。
2. 不得移除软件中显示的版权声明（见启动器“关于”页）。

HMCL 原始说明文档保留在 [docs/README_HMCL_zh_Hans.md](docs/README_HMCL_zh_Hans.md)。
